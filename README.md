# ARIS LP（株式会社VEXUM）

静的サイト（HTML / CSS / JS）。ビルド不要。`main` へ push すると Vercel が自動デプロイします。

- `index.html` … ページ本体
- `css/style.css` … スタイル（赤黒の入口 → 青の本編）
- `js/data.js` … 事例・20領域・FAQ などの文言データ
- `js/main.js` … スクロール演出・3D・インタラクション
- `assets/` … 画像（パンフレットから抽出）

ローカル確認: `python3 -m http.server 8000` → http://localhost:8000
